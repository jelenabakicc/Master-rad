# Sorting Visualizer - Android Application

## Technology Stack

- **Platform**: Android
- **Language**: Java
- **UI**: Android UI Toolkit with XML layouts
- **Charts**: MPAndroidChart
- **Build**: Gradle

## Getting Started

### Prerequisites
- Android Studio Arctic Fox or later
- Android SDK 24 or higher
- Java 8

### Building the Project

1. Clone the repository
2. Open in Android Studio
3. Sync Gradle files
4. Run on emulator or physical device


## Project Structure

```
├── algorithms/          # Sorting algorithm implementations
├── models/             # Data models (SortStep)
├── visualization/      # Custom views (ArrayBarView)
├── utils/              # Helper classes (ArrayGenerator)
├── MainActivity.java
├── VisualizationActivity.java
└── PerformanceActivity.java
```
